# Publications & Documentation

This directory contains papers and presentations that cover the OptimalPV_RH model, its methodology, and research results. It includes working papers, conference presentations, and related documentation organized by project version and publication venue.

## File Types

- **.csv**: Included in repo for quick reproducibility of presentation and paper graphs
- **.html**: Generated outputs plots for analysis and debugging (ignored, stored locally in `htmls/`)

## Version Control

- CSV results and documentation are tracked in git
- HTML outputs are excluded to keep the repository lean
- Large binary files (PDFs, graphics) should be considered for a separate release system
